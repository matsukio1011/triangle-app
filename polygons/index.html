多角形の内角・外角 公式チートシート

1. n角形の内角の和
内角の和 = 180° × (n - 2)

【なぜこの式？】 1頂点から対角線を引くと、多角形は (n - 2) 個の三角形 に分かれます。三角形の内角の和は 180° なので、180° × (n - 2) になります！

例: 10角形の内角の和 ➔ 180° × (10 - 2) = 180° × 8 = 1440°

2. 多角形の外角の和
外角の和 = 常に 360°

【なぜ常に360°？】 多角形の周りを1周回って元の向きに戻ると、ちょうど1回転（360°）回転します。何角形であっても、外角をすべて足すと必ず 360° になります！

3. 正n角形の「1つの外角」と「1つの内角」
1つの外角 = 360° ÷ n
1つの内角 = 180° - (1つの外角)

【解法のコツ】 正多角形の1つの内角を求めるときは、内角の和を n で割るよりも、「まず外角を求めて 180° から引く」 のが一番早くて計算ミスも減ります！

例: 正10角形 ➔ 外角 = 360° ÷ 10 = 36°、内角 = 180° - 36° = 144°

4. 割り切れないときの分数表記ルール

360 を n で割って割り切れない場合は、既約分数（これ以上約分できない仮分数） で表します。

  • 正7角形: 外角 = 3607°、内角 = 180° - 3607° = 9007°
  • 正11角形: 外角 = 36011°、内角 = 180° - 36011° = 162011°
  • 正14角形: 外角 = 360/14 を2で約分 ➔ 1807°、内角 = 180° - 1807° = 10807°
