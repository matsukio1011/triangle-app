# 多角形の内角・外角マスター (4択クイズアプリ)

n角形の内角の和、外角の和、正多角形の1つの角度（割り切れない場合は分数表記）を楽しく学べる4択クイズアプリです。

---

## 🌟 アプリの特徴

1. **出題バリエーションの網羅**:
   - **公式・性質**: $n$ 角形の内角の和 $180^\circ \times (n-2)$、外角の和 $360^\circ$、1つの内角・外角の公式
   - **内角の和の計算**: 10角形の内角の和 $180^\circ \times 8 = 1440^\circ$ など
   - **外角の和**: どんな多角形でも常に $360^\circ$ であることの徹底理解
   - **1つの外角・内角**: 正10角形の外角 $36^\circ$、内角 $144^\circ$ など
   - **割り切れない角度の分数表記**:
     - 正7角形の1つの外角: $\frac{360}{7}^\circ$
     - 正7角形の1つの内角: $\frac{900}{7}^\circ$
     - 正14角形の1つの外角: 約分して $\frac{180}{7}^\circ$
   - **逆算問題**: 「1つの外角が $36^\circ$ の正多角形は？ ➔ 正10角形」など

2. **「割り切れない角度は分数」の教科書スタイル表示**:
   - 独自の分数レンダラーにより、分子と分母が上下に並ぶ美しい分数形式（$\frac{360}{7}^\circ$ など）で表示されます。
   - 最大公約数（GCD）による自動約分にも対応し、既約分数学習にも役立ちます。

3. **🎨 オリジナル・ファビコン（Favicon）完備**:
   - インディゴ＆シアンのグラデーションに、正多角形・延長線・外角（ゴールド）・内角（シアン）をあしらった洗練されたアイコン。
   - ベクターSVG（`favicon.svg`）、高解像度PNG（`favicon.png`）、さらにHTML内インラインData URIにも対応しており、ローカル（`file:///`）で開いてもブラウザのタブに綺麗に表示されます。

4. **🏠 クイズ中いつでもトップへ戻れる安心設計**:
   - クイズプレイ画面のステータスバーに **「🏠 中断」ボタン** を設置。
   - 画面上部の **「🏠 トップ」ボタン** や、**タイトル（ロゴ）クリック** からも、いつでもスタート（モード選択）画面に戻れます。
   - 誤タップ防止の確認ダイアログ付きで、安心して操作できます。

5. **📐 図（ビジュアライザー）の表示・非表示切替**:
   - 右上の「📐 図: ON / 🚫 図: OFF」ボタン、またはスタート画面のチェックボックスから、いつでも図の表示／非表示を切り替えられます。
   - **図がONのとき**: 2カラムレイアウトで左側に多角形・延長線・外角・内角を色分け図解。
   - **図がOFFのとき**: 4択ボタンが中央にスッキリと配置され、図に頼らず頭の中の計算だけで解く本格的な特訓ができます。
   - 設定はブラウザに自動保存されます。

6. **PC画面でのノースクロール設計**:
   - クイズプレイ中は、図の有無に関わらず画面全体の高さを1画面内にピタッと収め、一般的なノートPCでも**スクロールバーが一切出ない完全ノースクロール**を実現しています。

7. **正解時の「自動次問スキップ」**:
   - 正解すると、正解音・アニメーションとともに **約0.75秒後に自動で次の問題へ進みます**。
   - 不正解の場合は自動で進まず、しっかり解説（公式や約分の手順）を確認したあと「進む」ボタンまたは `Enter` キーで次に進めます。

8. **🌙 ダークモード ＆ ⛶ 全画面表示**:
   - **🌙 / ☀️ ダークモード切替**: 目に優しいダークテーマとライトテーマをワンタップ切替。設定はブラウザに自動保存されます。Canvasの図形描画もダークモードに最適化。
   - **⛶ 全画面表示ボタン**: ワンクリックで画面いっぱいにクイズを表示。集中して取り組むことができます。

9. **学習を盛り上げる演出**:
   - Web Audio API による効果音（ピンポン♪ / ブブー♪ / 満点ファンファーレ♪）。
   - 音声ON/OFF切り替え機能付き。外部音源ファイル不要で完全オフライン動作します。
   - キーボード操作対応（1〜4キーで回答、Enterキーで次の問題へ）。

10. **「公式・早見表まとめ」タブ**:
    - なぜ内角の和が $180(n-2)$ になるのかの理由解説
    - なぜ外角の和が常に $360^\circ$ になるのかの理由解説
    - 正3角形〜正20角形までの角度一覧早見表

## 📚 収録モード

- **🌟 ランダム総合 (10問)**: すべての出題形式からバランスよく出題。
- **➗ 分数角度特訓 (10問)**: 正7角形や正14角形など、割り切れない分数角度を集中的に特訓。
- **📐 内角・外角の和 (10問)**: 内角の和の公式計算と外角の和360°の基本特訓。
- **🎯 1つの角度 (10問)**: 正多角形の1つの外角・内角に特化した特訓。
