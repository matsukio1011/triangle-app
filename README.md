# 📐 Geometry Lab 〜 数学・幾何学アプリ ポータル 〜

中学・高校数学の図形分野（平面幾何・空間幾何）を、インタラクティブな図形変形シミュレーションと4択クイズ、テストモードで直感的に探究・攻略できる学習Webアプリケーションスイートです。

ポータルサイト（`index.html`）から、目的の学習アプリを選択して利用できます。

### 1. 📐 三角形の心 & チェバ・メネラウス 学習アプリ (Geometry Explorer)
**ディレクトリ: `centers/`**

- **対象**: 中学2年〜高校1・2年（数学A 平面幾何）
- **主な機能**:
  - ⚡ **5心シミュレーター**: 三角形の頂点 $A, B, C$ を自由にドラッグ。重心（G）、内心（I）、外心（O）、垂心（H）、傍心（$I_A, I_B, I_C$）とオイラー線の連動をリアルタイム観察。
  - 📐 **チェバ・メネラウスの定理**: 内部点や直線上の制御点を操作し、一筆書き巡回ルートと分数計算（常に積＝1）を直感的に可視化。
  - 🎯 **4択クイズ（全48問）**: 定義・作図条件・中線の比・角の二等分線の定理などをステップバイステップ解説で完全マスター。
  - 📚 **まとめの図鑑**: 五心の定義・記号・作図のコツ・位置の規則性をまとめたリファレンスカード。

---

### 2. 📏 直角三角形・立体の垂線求積マスター (Altitude Quiz & Test)
**ディレクトリ: `altitude/`**

- **対象**: 中学3年〜高校1・2年（三平方の定理・空間図形）
- **主な機能**:
  - 🎯 **面積利用の高速解法**: 直角三角形の面積公式 $\frac{1}{2}ab = \frac{1}{2}ch$ を利用して垂線 $h = \frac{ab}{c}$ を素早く求める4択演習。
  - 🎲 **ランダム回転＆多彩な立体**:
    - 平面：直角三角形、長方形（4頂点から下ろす垂線）を15°刻み360°ランダム回転。
    - 立体：立方体および直方体において直交面を利用する直角三角形（$\triangle AFD, \triangle AEG, \triangle BDH, \triangle BFH, \dots$ など8パターン）。
  - ⚙️ **学習アシスト機能**:
    - 斜辺寸法の表示/非表示（`H` キー）
    - 解答数値の有理化あり/なし（`U` キー）
    - 図形の向きの再シャッフル（`R` キー）
  - 🏆 **10問連続合格テストモード**:
    - 第1問〜第4問：平面図形
    - 第5問〜第10問：立体図形
    - 斜辺表示OFF・有理化あり固定
    - 緊張感あふれるド派手なエラー音＆画面シェイク演出
    - 10問連続正解達成で大歓声の合格ファンファーレ＆紙吹雪（Confetti）演出！

## 💻 動作環境・起動方法

Webブラウザ（Google Chrome, Microsoft Edge, Safari, Firefoxなど）さえあれば、外部サーバーや特別なインストール作業なしに即座に利用可能です。

### ローカルでの起動方法
ルートディレクトリの `index.html` をブラウザでダブルクリックして開くだけで動作します。

```bash
# Windows コマンドラインから起動する場合
start index.html
```

### GitHub Pages での公開
GitHub Pagesのソースを `main` ブランチのルート（`/`）に設定することで、Web上ですぐに公開・アクセス可能です。

## ⌨️ ショートカットキー一覧

### ポータル画面 (`index.html`)
| キー | 機能 |
| :--- | :--- |
| `1` | 三角形の心 & チェバ・メネラウス 学習アプリを起動 |
| `2` | 垂線求積マスターを起動 |
| `F` | 全画面表示 / 通常表示 切替 |

### アプリ各画面
- 各アプリのヘッダーにある **「🏠 ポータル」** ボタンで、いつでもポータル画面へ戻ることができます。
- **全画面表示**: どちらのアプリもヘッダー右上のボタンまたは `F` キーで全画面表示の切替が可能です。
