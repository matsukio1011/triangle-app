# 📐 三角形の心 & チェバ・メネラウス 学習アプリ (Geometry Explorer)

高校数学・中学数学で登場する「三角形の五心（重心・内心・外心・垂心・傍心）」および「チェバの定理・メネラウスの定理」を、インタラクティブな図形操作とクイズで直感的にマスターできる学習Webアプリケーションです。

---

## 🚀 主な機能

### 1. 🎯 4択クイズ（全48問）
- **基礎から応用まで網羅**: 中学範囲の3心（重心・内心・外心）から高校範囲（垂心・傍心）までカバー。
- **定理・性質の徹底攻略**:
  - 重心・内心・外心の定義、形状による位置の変化（鋭角・直角・鈍角）
  - **垂直二等分線の性質**（両端からの等距離、2点から等距離の点の軌跡、作図条件）
  - **角の二等分線の性質**（2辺からの等距離、内角の二等分線と比の定理 $AB : AC = BD : DC$）
- **スマート出題アルゴリズム**: 毎回ランダムに出題されつつ、3回に1回は「定義問題」が偏りなく復習として登場。
- **学習UX**: 出題時はネタバレ防止、回答後に正解を緑色ハイライト＋正解バナー＋詳しい解説・ヒント・SVG図解を表示。
- **サウンド機能**: Web Audio API による軽快な正解音・不正解音、連続正解カウント（🔥）。

### 2. 🔍 5心シミュレーター
- 三角形の頂点 $A, B, C$ をドラッグして形状を自由自在に変形。
- 重心（G）、内心（I）、外心（O）、垂心（H）、傍心（$I_A, I_B, I_C$）の動きをリアルタイム観察。
- 外接円・内接円・傍接円の描画、中線・角の二等分線・垂直二等分線の表示切替。
- **オイラー線（Euler line）** の可視化（外心・重心・垂線が一直線上に並ぶ幾何学の神秘）。

### 3. 📐 チェバ・メネラウスの定理 シミュレーター
- **チェバの定理**: 三角形内部のチェバ点 $O$ をドラッグ操作。一筆書き巡回ルート（矢印）とリアルタイム分数計算バー（常に積が1.00）。
- **メネラウスの定理**: メネラウス直線上の2制御点をドラッグ。高校生がつまずきやすい「キツネ型図形」や外分点への巡回ルートを直感的に可視化。
- **出発点切り替え**: 頂点 $A, B, C$ のどこからでも一筆書きをスタート可能。数式・巡回矢印が完全同期。

### 4. 📖 まとめ図鑑
- 五心の定義・記号・性質・作図のコツ・位置の規則性をまとめたリファレンスカード。

## 💻 動作環境・技術仕様

- **技術スタック**: HTML5, CSS3, JavaScript (Vanilla JS / フレームワーク不要), SVG, Web Audio API
- **レスポンシブ & テーマ**: PCワイド画面に完全フィット（スクロール不要）、ダークモード / ライトモード両対応。
- **実行方法**: `index.html` をブラウザで直接開くだけで即座に動作します（Webサーバー不要、ローカル環境でも完全動作）。
